Purpose

Read-only market research for studying public Etsy active listings in digital-product categories and identifying patterns around price, competition, concentration, and new-seller visibility.

Research Status

Current phase: RQ2 new-seller visibility research.

  • Live pilot is blocked until local Etsy API credentials are present.
  • API rank is not the same as user-visible Etsy SERP rank.

What It Does

  • reads public active listing data
  • analyzes pricing patterns
  • measures market concentration
  • studies new-seller visibility
  • supports reproducible product opportunity research

What It Does Not Do

  • create or edit Etsy listings
  • delete listings or place orders
  • send messages or manage shops
  • access private member data
  • collect passwords or cookies

Data & Privacy

Research outputs are stored locally. API credentials are kept in local environment variables and are never published.

API Usage

Etsy Open API v3 is the primary marketplace data source.
