Purpose

Read-only market research for studying public Etsy active listings in digital-product categories and identifying aggregate patterns around price, competition, concentration, and new-seller visibility.

Research Status

Current phase: RQ2 new-seller visibility research.

  • Live pilot is blocked until local Etsy API credentials are present.
  • API ordering is not represented as user-visible Etsy SERP ranking.

What It Does

  • reads public active listing data through Etsy Open API
  • analyzes aggregate pricing patterns
  • measures market concentration
  • studies new-seller visibility
  • supports reproducible product opportunity research

What It Does Not Do

  • create or edit Etsy listings
  • delete listings or place orders
  • send messages or manage shops
  • access private member data
  • collect passwords, cookies, or session tokens
  • scrape, crawl, or automate Etsy.com pages

Data & Privacy

API credentials are kept in local environment variables and are never published. Live Etsy member content is treated as temporary working data; durable outputs are designed around aggregate research metrics rather than long-term member-content archives.

API Usage

Etsy Open API v3 is the supported programmatic marketplace data source for this project.
