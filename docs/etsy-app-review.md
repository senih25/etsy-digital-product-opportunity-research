# Etsy App Review

- Application Name: Digital Product Opportunity Research
- Website: https://senih25.github.io/etsy-digital-product-opportunity-research/
- Application Type: Seller Tools
- Users: Only me or colleagues
- Commercial Purpose: Yes
- Uploads/Edits Listings: No
- Reads Sales Data: No
- Sends Email: No
- Research Use: Read-only public marketplace analysis
- OAuth: Not used for current RQ2 research
- Credentials: Stored locally only

Description:

Read-only market research tool using Etsy Open API public endpoints to analyze active listings, pricing, competition, product categories, and new-seller visibility. It does not create, edit, delete, purchase, message, or manage listings, shops, orders, or accounts. Research data is stored locally. No private member data is accessed and no seller OAuth is used.
