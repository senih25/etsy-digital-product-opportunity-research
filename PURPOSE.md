# Purpose

This repository exists to support read-only market research on publicly available Etsy active listings.

It is intended for digital product opportunity research, especially RQ2 new-seller visibility analysis in functional tool categories.

This project:

- reads public active listing data
- analyzes pricing, competition, concentration, and category structure
- supports reproducible local research outputs
- does not mutate listings, shops, or orders
- does not send messages
- does not collect passwords, cookies, or private member data
- does not rely on a scraping-first architecture

Primary marketplace data source: Etsy Open API v3.
