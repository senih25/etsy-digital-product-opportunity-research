# Security

Security scope: local-first research CLI and public documentation repository.

Credential handling:

- environment variables only
- no credentials in commits, issues, screenshots, logs, or discussions
- no API keystrings or shared secrets in tracked files

Data handling:

- no private member data
- no session tokens
- no browser cookies
- raw research data remains local by default

Operational limits:

- no write scopes for the current RQ2 workflow
- no Etsy listing or shop mutation
- no hidden automation against private Etsy surfaces
