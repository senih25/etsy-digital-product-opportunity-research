# Privacy

This project analyzes public marketplace listings and aggregate market patterns.

- no private Etsy member data is collected
- no seller OAuth is used for the current RQ2 workflow
- no account passwords are collected
- no cookies or session tokens are collected
- API credentials remain local environment variables and are never committed
- raw research data remains local by default
- the public repository contains source code, synthetic fixtures, and sanitized documentation
- no analytics or tracking scripts are required for the research CLI
- no data resale
- no behavioral profiling of individual Etsy members

The repository is read-only with respect to Etsy marketplace operations.
